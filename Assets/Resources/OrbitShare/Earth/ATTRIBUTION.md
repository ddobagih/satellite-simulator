## Changes made here

- Downloaded via Wikimedia Commons `Special:Redirect/file` links.
- Renamed files to Unity-friendly names used by OrbitShare.
- Converted normal/specular source `.tif` files to `.jpg` for consistent Unity resource names.
- Added Unity `.meta` files for import settings; Unity may rewrite them on import.
- Generated 4K fallback JPGs (`*_4K.jpg`, 4096x2048) from the 8K JPGs for runtime performance fallback/loading.
