# OrbitShare 발표 재작성 대상 슬라이드(3페이지, 5페이지 이후)

## 3페이지
- 제목: 메시지 전송 파이프라인
- 부제목: 핵심 흐름
- 내용:
  - 메시지 작성 → 업링크 → ISL → 다운링크 → 수신 완료

## 5페이지
- 제목: 메시지 작성 - 시간
- 부제목: 패널 오픈과 시간 설정
- 내용:
  - 발신 시각과 예약 시각을 구분해 입력 값을 처리
  - 현재 시각 또는 예약 시각 선택
  - 입력 검증 실패 시 즉시 피드백을 표시

## 6페이지
- 제목: 메시지 작성 - 메시지
- 부제목: 텍스트 입력과 첨부 처리
- 내용:
  - 본문 문자열 길이와 바이트로 용량을 산정
  - 첨부 파일 크기 제한을 적용해 전송 파라미터 고정
  - 메시지 데이터 변경 시 후보 추천 후보군을 자동 갱신

## 7페이지
- 제목: 메시지 작성 - 위치
- 부제목: 목적지 선택과 경로 전제 조건 설정
- 내용:
  - 발신지/목적지 노드 목록을 고정 노드셋 기반으로 제공
  - 위치 변경 시 거리·가시성 계산 조건을 즉시 반영
  - 노드 메타데이터(좌표·시간)로 후보군을 초기 필터링

## 8페이지
- 제목: 메시지 작성 - 위성망
- 부제목: 후보 위성 확인과 선택
- 내용:
  - 가시성/품질 점수에 따라 위성 후보를 우선 정렬
  - 선택된 위성의 점수, 거리, 리턴 시간 정보를 노출
  - 확정 전 최종 요약값 재검증을 통해 전송 오차 방지

## 9페이지
- 제목: 메시지 작성 - 확인
- 부제목: 실행 확정 및 전송 진입
- 내용:
  - 메시지 타입/첨부량/도착 조건을 최종 확정
  - MissionManager로 상태 머신 진입 후 단계 제어
  - 실패·재시도·완료 로그가 통합 패널에 기록

## 10페이지
- 제목: 실시간 위성 시스템
- 부제목: 실행 파이프라인
- 내용:
  - CelesTrak ISS/STATIONS/ACTIVE/STARLINK에서 궤도 정보를 수집
  - 파싱 실패 시 캐시 데이터로 폴백 렌더링
  - 실시간 위성 개체 생성, 라벨링, 라인업데이트를 프레임 기준으로 갱신
  - 현재 시각과 위성 위치 변환을 동기화해 시각 상태를 유지
  - 그룹/범례 전환과 고대비 모드에서의 표시 안정성을 분리 제어

## 11페이지
- 제목: 애니메이션
- 부제목: 프로젝트 내 사용 애니메이션
- 내용:
  - 위성 궤도 이동 라인 렌더 애니메이션
  - 위성 하이라이트/선택 강조 라인 펄스
  - 연결선 생성·삭제 페이드/스케일 인터폴레이션
  - 패킷/전송 아이콘 순차 이동 애니메이션
  - 통신 단계 진행률 바 잔차 트랜지션
  - 큐 상태 전환 시 패널 슬라이드/토글 애니메이션
  - 실시간 위성 라벨 업데이트 및 색상 전환 전환 효과
  - 패널 포커스 전환 시 페이드/스케일 블렌딩

## 12페이지
- 제목: 경로 계산
- 부제목: 사용 알고리즘 구성
- 내용:
  - 발신·목적지·시간 기반의 후보군 1차 필터링
  - 거리·각도 조건으로 가시성/연결 가능성 제약 적용
  - 신뢰도와 품질 점수를 정규화해 가중치 산출
  - 정렬 기준(품질/거리/신뢰도) 기반 추천 순위 계산
  - 동일 우선순위 처리 시 안정 정렬로 재현성 확보
  - 결과 누락 방지를 위한 예외 후보 보정 로직

## 13페이지
- 제목: 통신 단계 시각화
- 부제목: uplink / ISL / relay / downlink
- 내용:
  - 단계 진행률과 퍼센트 상태 동기화
  - 패킷 스트림/선 연결을 통한 네트워크 흐름 표시
  - 완료 단계별 상태 확인 로그 누적
  - 재실행/리플레이 시퀀스 반복 가능

## 14페이지
- 제목: 상태
- 부제목: 큐/기록/재시도
- 내용:
  - 대기 큐를 통한 연속 요청 처리
  - 실패 항목 재시도 및 기록 보존
  - 히스토리 패널에서 성공/실패 항목 조회
  - 요청 ID 단위 상태 추적

## 15페이지
- 제목: 접근성·설정
- 부제목: 운영 제어
- 내용:
  - 고대비 모드 토글로 가시성 강화
  - 패널 정렬·크기·닫힘 동작 조절
  - 설정 값 영속 저장
  - 상태 패널 레이아웃 커스텀
