# 2026-05-31 작업 로그

## 실제 위성 TLE/SGP4 시각화 1차 구현

### 한 일
- Space-Track 로그인 세션/쿠키/비밀값은 사용하지 않고, CelesTrak 공개 GP/TLE 엔드포인트 기반으로 구현했다.
- CelesTrak TLE 데이터 계층을 추가했다.
  - ISS: `CATNR=25544&FORMAT=TLE`
  - ACTIVE: `GROUP=ACTIVE&FORMAT=TLE`
  - STARLINK: `GROUP=STARLINK&FORMAT=TLE`
  - UnityWebRequest fetch, 2시간 메모리 캐시, stale cache/fallback, 내장 ISS fallback을 추가했다.
- TLE parser를 추가했다.
  - 3-line/2-line TLE를 파싱하고 name, NORAD ID, epoch, inclination, RAAN, eccentricity, argument of perigee, mean anomaly, mean motion, BSTAR, 원문 line1/line2를 보존한다.
- 궤도 전파/좌표 변환을 추가했다.
  - `Sgp4Propagator.TryPropagate(...)`로 TLE 기반 현재 ECI 위치/속도 계산 API를 제공한다.
  - 구현은 Unity 시각화용 near-earth Kepler + 1차 J2 세차 baseline이며, 정밀 Vallado SGP4 전체 구현은 아니다.
  - ECI→ECEF, ECEF→위경도/고도, ECEF/ECI→Unity 좌표, velocity 방향 변환을 추가했다.
- Unity 시각화 컴포넌트를 추가했다.
  - `RealSatelliteVisualizer`가 CelesTrak TLE를 받아 ISS를 지구 주변에 표시한다.
  - `RealSatelliteMarker`가 marker, 라벨, velocity 방향 line을 표시한다.
  - `1/2/3` 키로 ISS/ACTIVE/STARLINK 로드를 전환할 수 있게 했다. 그룹 표시는 `groupDisplayLimit`로 제한한다.
- 부트스트랩과 검증을 연결했다.
  - `OrbitShareBootstrap`에서 `CelesTrakTleClient`와 `RealSatelliteVisualizer`를 생성하고 Earth/Satellites root에 연결했다.
  - 자동 검증 리포트에 실제 CelesTrak ISS TLE URL, 표시 수, 위경도/고도 sanity check를 추가했다.

## UI/UX 패널·경로선 가독성 추가 개선

- 실제 궤도선/지표 궤적과 선택 궤도선 alpha/width를 더 낮췄다.
