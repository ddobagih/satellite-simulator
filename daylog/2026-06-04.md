## 메시지 작성/위성망/상태 UI 추가 수정

- 시간 탭 직접 설정 달력을 빠른 선택 버튼 아래에 표시하도록 재배치하고, 버튼/달력/하단 흐름 버튼 겹침을 줄였다.
- 모든 UI 버튼 라벨의 체크 표시(`✓`)를 제거했다. 선택 상태는 버튼 색상으로만 표시한다.
- 달력 날짜 버튼 배경을 같은 계열로 통일하고, 스크롤 가능한 예약 범위를 365일로 확장했다.
- 메시지 입력 필드에 두벌식 raw-key fallback 조합을 추가해 Linux/Legacy InputField에서 `dkssud` 같은 입력도 `안녕`으로 조합되도록 했다.
- 용량 표기를 `Bytes`로 통일했다.
- 위성망 추천 즐겨찾기 버튼/정렬 가중치를 제거하고, 추천 리스트를 `경로`, `통신 가능 시간`, `예상 가격`, `성공률`, `전송시간` 세로 표시로 바꿨다.
- 위성 상세 정보에서 운영/실제 TLE/궤도/속도/연결 시간/양방향 가시권/도착 예상 정보를 제거하고, 요청 항목만 콜론 형식으로 표시하게 했다.
- 실제 TLE 고도/속도는 유지하면서 요금/지연/성공률/혼잡도 UI 산정값을 위성별 hash 기반으로 다르게 넣어 필터 차이가 느껴지게 했다.
- 확인 탭에서 `전송 확인` 제목과 구분선을 제거하고, 송신지/수신지를 `경로 : A -> B` 한 줄로 합쳤다. 요금 문구의 `빠른 전송` 라벨도 제거했다.
- 전송 상태 창에서 작성된 메시지가 없을 때 경로와 업링크/ISL/다운링크 그래프를 숨기고 `전송중인 메시지가 없습니다`를 표시하게 했다.
